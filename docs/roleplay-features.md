# Roleplay Features

A few small features that make roleplay and everyday hanging-out easier - none of them are required
to play, but they go a long way for immersion.

## Sit

Shift-right-click an empty-handed stair or slab to sit on it. Sneak, jump, or die to stand back up.

## Voice chat

The server runs proximity voice chat - you'll need the **Simple Voice Chat** mod installed
client-side to use it (it's optional, not required to join the server). Once installed:

- Voice carries up to **48 blocks**, so nearby players hear you naturally as you walk around.
- Whispering carries a shorter **24 blocks**, for quieter conversations.
- Group channels are supported if you want a private call with specific people.

We encourage using voice chat where you can - it makes diplomacy, wars, and roleplay a lot more fun.

## Dual horse mounts

Two players can ride the same horse (or donkey, mule, skeleton horse, or zombie horse) at once - one
steering, one along for the ride. Handy for escorting someone, roleplaying a patrol, or just travelling
together without needing two mounts.
