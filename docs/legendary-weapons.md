# Legendary Weapons

Rare, hand-buffed vanilla weapons scattered around the world in small shrines. Only a handful of
each exist at any one time.

```
/legendary check
```

Shows every shrine currently uncollected, with coordinates and which weapon type it holds.

## The four weapons

- **Longsword** - higher base damage than a normal sword, with a slightly slower swing.
- **Greatsword** - even higher base damage, slower again.
- **Battle Axe** - the hardest-hitting of the four, with a built-in Sweeping Edge enchant vanilla
  never allows on an axe. Slowest swing speed.
- **Compact Bow** - fires arrows faster and harder than a normal bow.

These aren't stacked with unusual enchantments out of the box - they're just genuinely stronger
versions of their base weapon. You can enchant one further at an enchanting table or anvil exactly
like any other gear.

Only 5 of each type can exist in the world (or in players' hands) at once. Losing one, whether it
despawns, burns in lava, or falls into the void, frees up a slot for a new one to eventually spawn
in a shrine somewhere else.
